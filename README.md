# 📊 Sales Analysis Dashboard — Power BI

An interactive Power BI dashboard designed to analyze sales performance, profitability, customers, and regional trends.

## 🛠️ Tools & Technologies

* Power BI
* Power Query
* DAX
* Excel / CSV
* Data Visualization

## 📌 Dashboard Features

* Total Sales
* Total Profit
* Total Orders
* Sales by Region
* Sales by Category
* Monthly Sales Trends
* Top-performing Products
* Interactive filters and slicers
